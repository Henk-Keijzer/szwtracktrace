Nutzung
Mit dieser App können Sie den Verlauf einer Reihe von Segelrennen (beschleunigt) wiedergeben und, wenn das Rennen noch läuft, live verfolgen. Klicken Sie auf den Namen des Rennens oben im Bild und wählen Sie ein Rennen, das Jahr, in dem es gesegelt wurde, und falls nötig den Tag. Das Rennen wird dann geladen. Sobald das Rennen geladen ist, setzen Sie die Schiffe mit dem Start/Stop-Knopf unten links auf dem Bildschirm in Bewegung. Mit dem vertikalen Schieberegler bestimmen Sie die Wiedergabegeschwindigkeit.

Oben rechts auf dem Bildschirm sehen Sie die Knöpfe für das Teilnehmer-Menü und das Karten-Menü.

Mit dem Teilnehmer-Menü können Sie festlegen, wie die App eine Anzahl oder alle Schiffe automatisch verfolgt. Mit dem Häkchen "Alle Schiffe an/aus" können Sie die Häkchen hinter den Schiffen auf einmal alle an- und ausschalten.
Ein Doppelklick auf das Symbol eines Schiffes auf der Karte wählt nur dieses Schiff zum Verfolgen aus. Gleichzeitig öffnet sich das Teilnehmer-Menü und Sie können ein oder mehrere weitere Schiffe zum Verfolgen anwählen.
Mit den "folgen" und "zoomen" Knöpfen unten rechts auf dem Bildschirm sorgen Sie dafür, dass alle angekreuzten Schiffe nicht aus dem Bild verschwinden.
Wenn Sie auf den Namen eines Schiffes im Teilnehmer-Menü klicken, erhalten Sie zusätzliche Informationen zu diesem Schiff, sofern verfügbar.

Mit dem Karten-Menü können Sie aus verschiedenen Kartenhintergründen wählen und andere Detailinformationen auf der Karte anzeigen oder verbergen.

Bei einem "Live"-Rennen können Sie den früheren Verlauf des Rennens beschleunigt anzeigen, indem Sie den Zeit-Schieberegler unten im Bild nach links schieben und die Wiedergabe starten. Sobald das Ende erreicht ist, wird automatisch wieder auf Live umgeschaltet.

Wenn Sie einen Asterix hinter dem Namen eines Schiffes sehen (z.B. Name'), bedeutet dies, dass die empfangene GPS-Position nicht aktuell ist. Die auf der Karte angezeigte Position ist dann nicht unbedingt die tatsächliche Position.

Die Tracks werden so weit wie möglich lokal auf Ihrem Telefon/Tablet/Laptop/PC gespeichert. Dennoch müssen regelmäßig Informationen vom Server heruntergeladen werden. Wenn Ihr Datenvolumen knapp ist, wählen Sie ein älteres Rennen nur, wenn Sie sich im WLAN befinden.

Karten
Die Standardkarte, die graue Karte und die Karte mit blauen Wasserakzenten stammen vom Kadaster. Die Satellitenbilder sind von ©Esri, Maxar, Earthstar Geographics und der GIS User Community. Die Rechte an der Open Street Map und Open Sea Map liegen bei ©Open Street Map creators und den ©Open Sea Map creators. Die Overlay-Karte mit den Fahrwassermarkierungen stammt von Rijkswaterstaat. Leider sind nicht alle Bojen auf den Binnengewässern darauf enthalten.

Windy.com
Vor oder während eines Live-Rennens sehen Sie im Menü oben rechts einen Knopf für Windy. Wenn Sie darauf klicken, öffnet sich ein Fenster mit der Windvorhersage von Windy.com.

Buienradar
Buienradar liefert die Winddaten während der Veranstaltungen. Durchschnittlich jede halbe Stunde übermitteln über 50 Wetterstationen ihre aktuellen Daten an www.buienradar.nl. Und wir dürfen diese Daten nutzen.
Wenn Windinformationen verfügbar sind, können Sie im Karten-Menü die Windpfeile und die Windsimulation auf der Karte an- und ausschalten.
Achtung: Die Windsimulation erfordert eine erhebliche Rechenleistung. Wenn Sie längere Zeit mobil zuschauen, kann Ihr Akku schnell leer werden.

AIShub
Während unter anderem des Beurtveer, der Strontrace (schwere Klasse), der Slag in de Rondte und der Waddenrace werden die Dienste von AIShub.net zur Verfolgung der Schiffe genutzt.
